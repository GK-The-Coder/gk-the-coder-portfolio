# Certificate Images

Store your certificate images in this folder.

## How to Add Certificates

1. **Copy your certificate images** to this folder
   - Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`
   - Recommended size: 1920x1080 or similar landscape ratio
   - Keep file names simple (no spaces): `aws-certificate.jpg`, `google-cloud.png`

2. **In the admin dashboard**, use the path format:
   ```
   /certificates/your-image-name.jpg
   ```

## Examples

If you have a certificate image named `aws-certified-developer.jpg` in this folder, use:
```
/certificates/aws-certified-developer.jpg
```

If you have `google-cloud-architect.png`:
```
/certificates/google-cloud-architect.png
```

## File Naming Tips

✅ Good names:
- `aws-solutions-architect.jpg`
- `google-cloud-engineer.png`
- `microsoft-azure-fundamentals.jpg`

❌ Avoid:
- `my certificate.jpg` (spaces)
- `cert 123.png` (spaces)
- `IMG_20240101.jpg` (unclear)

## File Size Optimization

For best performance:
- Compress images before uploading (use tools like TinyPNG, Squoosh)
- Aim for under 500KB per image
- Use WEBP format for smaller file sizes
