# Achievement Images

Store your achievement photos in this folder.

## How to Add Achievements

1. **Copy your achievement images** to this folder
   - Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`
   - Recommended size: 1920x1080 or similar landscape ratio
   - Keep file names simple (no spaces): `hackathon-winner.jpg`, `coding-competition.png`

2. **In the admin dashboard**, use the path format:
   ```
   /achievements/your-image-name.jpg
   ```

## Examples

If you have an achievement image named `hackathon-first-place.jpg` in this folder, use:
```
/achievements/hackathon-first-place.jpg
```

If you have `coding-contest-winner.png`:
```
/achievements/coding-contest-winner.png
```

## File Naming Tips

✅ Good names:
- `hackathon-2024-winner.jpg`
- `coding-competition-gold.png`
- `tech-fest-first-prize.jpg`

❌ Avoid:
- `my achievement.jpg` (spaces)
- `IMG_20240101.jpg` (unclear)
- `achievement 1.png` (spaces)
